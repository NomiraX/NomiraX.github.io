深度学习到大模型：一条被验证过的学习路径

文章发布时间:
2026-10-17

这是整个系列的最后一集。不学新东西，只把前面三十几节的主线串起来:每个知识点挂在训练循环的哪一环，以及一条从 Python 走到大模型的路。

整理自 B 站视频：深度学习课程内容串联&学习路径总结

一、先区分机器学习与深度学习

机器学习 深度学习
特征 人工设计，人能理解 模型自己学出来
数据形态 结构化（能放进表格） 非结构化（图像、音视频、文本）
计算 一次运算出结果 多层网络反复训练
成本 低 高得多

一句话：深度学习是让模型自己学特征。代价是网络变复杂、训练变贵。

二、神经网络是怎么被「发明」的

异或问题是最重要的标志：它证明了「堆更多线性层没用」，必须要有非线性。

三、训练的循环只有四步

步骤 做什么 谁负责
1. 前向传播 输入过网络，得到预测 网络结构
2. 算损失 和真实标签比，错得多离谱 损失函数
3. 反向传播 每层该为这个误差负多大责任 链式法则
4. 更新参数 沿着损失下降的方向挪一点 梯度下降 / 优化器

后面所有知识点，都在这个循环的某一环里。这是把整门课串起来的那根线。

四、激活函数：给网络非线性的能力

没有激活函数时，无论叠多少层，本质都是线性叠加，等于只有一层。

函数 特点 现在还用吗
ReLU max(0,x)，最简单最常用 主流
Sigmoid 压到 0–1，二分类、门控常用 用，但深层网络少
Tanh 零中心，比 Sigmoid 平滑 少一些
Leaky ReLU 负半轴也不完全为 0 小幅优化
GELU 更平滑，接近人脑的软门控 Transformer 用
SiLU / Swish 门控 + 更平滑 现代大模型用得多

五、损失函数：只回答「错了多少」

任务 损失
回归 均方误差 MSE
分类 交叉熵

它只给出一个总数，不负责告诉每一层该改多少——那是反向传播的事。

六、反向传播与梯度下降

PyTorch 里这一步是自动的（loss.backward()）。

反向传播只算梯度，不更新参数。真正更新的是梯度下降：

梯度的方向是损失上升最快的方向，所以要沿负梯度走。学习率决定「一步走多远」：

学习率 后果
太大 一步迈过头，来回震荡，训练更慢
太小 方向对，但要走很多步，也慢
合适 需要经验，这个经验就是超参数

七、优化器：梯度下降的各种落地方式

优化器 加了什么 解决什么
SGD（mini-batch） 每次只抽一部分样本算梯度 全量太慢
Momentum 惯性 冲过平坦期
自适应学习率 每个参数不同步长 有的参数已接近最优，有的还很远
RMSProp 抑制学习率一路衰减到零 自适应学习率的副作用
Adam 惯性 + 自适应 两者结合
AdamW 把权重衰减从梯度更新里拆出来 Adam 实现上的小 bug

实践建议：小实验用 SGD 就够，调大模型要精确结果用 AdamW（成本略高）。

八、能训练 ≠ 训练得好：稳定性三件套

手段 解决什么
学习率调度 前期快、后期稳
参数初始化 让第一轮的前向和梯度都不炸
归一化 训练过程中每一步都保持分布稳定

学习率调度

策略 做法
Step Decay 每过固定步长降一点，比较机械
Cosine Annealing 用余弦曲线平滑下降
Warmup + Cosine 先从小学习率升到顶点，再退火

Warmup 的作用很像跑步前的拉伸：不让模型一上来就用极限步长，先适应，再提速，最后慢慢收。

参数初始化

做法 后果
全初始化为 0 或同一个值 对称性不破，所有参数梯度相同，等于只有一个参数
随机但幅度太小 逐层连乘后信号消失（梯度消失）
随机但幅度太大 逐层放大后失控（梯度爆炸）
Xavier 配 Sigmoid / Tanh
Kaiming（He） 配 ReLU 系（考虑了负半轴的不对称）

偏置通常初始化为 0 就好。

归一化

参数初始化只管第一次前向；训练中参数一直在变，所以每一步都要归一化一次。

类型 归一化维度 常用领域
BatchNorm 同一批次、不同样本的同一特征 图像
LayerNorm 单个样本内部横向 NLP / Transformer

九、泛化四件套：别过拟合

过拟合的典型曲线：训练集一路变好，验证集到了某个拐点反而变差。

手段 机制
L1 正则 把一部分权重压成 0，鼓励稀疏；适合人工筛特征
L2 正则 让所有权重整体变小，抑制大权重但不归零
权重衰减 更新时额外乘一个缩小系数，像给权重系了根弹簧
Dropout 随机关掉一部分神经元，逼模型不依赖某个特征
Early Stopping 连续 N 轮验证集没变好就停

L1 在机器学习里用得多（特征是人选的，能确定哪些没用）；深度学习里更常用 L2 / 权重衰减，因为图像、文本、音频里很难断言哪个特征百分之百无用。

十、CNN：为什么它适合图像

先回答「为什么不能直接上 MLP」：图像数据量太大，全连接会让参数爆炸。

CNN 的核心是把图像的先验知识写进网络结构，从而省参数：

先验 带来的收益
局部性 相邻像素相关性更强，不必全连接
参数共享 一个卷积核扫全图，识别同一类特征
平移等变 眼睛在左在右都是眼睛，数据等效变多
层次组合 边缘 → 纹理 → 局部部件 → 物体

越浅的层识别边缘和方向，越深的层识别眼睛、耳朵这类语义部件。

十一、NLP 的六次跳跃

阶段 解决了什么 遗留问题
One-hot 把词变成向量 维度爆炸、没有语义
Word2Vec / Embedding 稠密、可训练、语义相近就靠近 不看上下文
RNN 处理不定长；隐藏态携带历史；参数共享 一个隐藏态要装下全部历史，长序列必丢
LSTM / GRU 门控：有选择地记、有选择地忘 只是缓解，没根治
Seq2Seq 编码器 + 解码器，输入输出长度可以不同 仍然靠 RNN，仍是串行
Attention 解码时动态回看每个位置，加权求和 还带着循环
Transformer 自注意力，全部并行 参数与算力需求暴涨

注意力那一步很关键：以前是把整句压成一个上下文向量交给解码器，越靠前的信息丢得越厉害；有了注意力，解码每一步都能自己算「现在该重点看原文的哪里」。

十二、Transformer 再走一遍

自注意力能让每个位置一次看到全序列，所以可以并行；RNN 的 h2 依赖 h1、h3 依赖 h2，只能串行。这是训练效率差距的根源。

十三、三条分支

架构 用了哪部分 擅长 不擅长
BERT 只有编码器，双向 表示学习、分类 生成
GPT 只有解码器 续写、对话 双向理解
T5 编码器 + 解码器 一切转成文本到文本 结构更重

十四、大模型训练的三个阶段

阶段 做什么 产出
预训练 海量语料上学语言规律与世界知识 基座模型
指令微调（SFT） 用有监督的问答、摘要、翻译、代码数据学「听指令、按格式回答」 指令模型
后训练 人类偏好与安全对齐（RLHF / DPO），学拒答与工具使用 可用的对话模型

十六、两个高频误区

误区 实际
数学要先把高数线代全啃完 实际用到的不到教材的十分之一；忘了就针对性地补，比如矩阵乘法、链式法则
要把 PyTorch 的 API 背下来 API 海量且可查、可让模型生成；只需知道有哪几个核心模块、关键 API 干什么

核心原则是用到什么学什么，不要为了「打基础」把所有前置知识都学一遍再开始。

十七、值得补的公开课

课程 适合补什么
CS224N NLP 基础：向量、序列模型、Transformer
CS324 大模型的概念、理论与风险
CS336 从零实现高效的语言模型训练（要有理论基础）
Karpathy 的 nanoGPT 在不懂理论的情况下，被引导着一步步写出 GPT

小结

  1. 整门课的主线是那四步循环：前向 → 损失 → 反向传播 → 更新；所有技巧都挂在这四步上。
  2. 稳定性靠学习率调度、参数初始化、归一化；泛化靠正则化、权重衰减、dropout、early stopping。
  3. CNN 省参数靠先验，RNN 处理序列靠隐藏态，Transformer 能并行靠自注意力。
  4. 预训练给知识，指令微调给格式，后训练给偏好与安全。
  5. 路径是 Python → 机器学习 → 深度学习 → 大模型 / Agent；数学和 API 都边用边补。

系列到此结束。下一门课转向 Agent 开发——那是把前面这些「理解语言」的能力，变成「能动手做事」的能力。
