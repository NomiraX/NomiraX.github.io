AI Agent 编年史：从 ChatGPT 到 Muse（2022–2026）

文章发布时间:
2026-11-15

整理自 B 站视频：3万字干货真人讲解 AI Agent 编年史，从 chatGPT 到 muse 一个视频全看懂【重制版】，结构参考了同题材的公开长文，内容按复习需要做了大幅精简。这篇是速查笔记：每一代只留一句话结论、关键节点和教训，要看细节请回看原视频。

导读：这份笔记怎么用

一句话：Agent = 模型 + Harness。

模型负责「想」，Harness 负责其余的一切：喂它什么指令和上下文，给它什么工具，谁来驱动循环，怎么判断做得对不对，它跑在哪台电脑上、能动什么，以及人怎么查看和验收。

七件套是全文的主线——每一代的历史，都是这七件里某几件在扩张。

部件 它回答的问题 2022 → 2026 的演化
① 指令 做什么、按什么规矩做 提示词 → 自定义指令 → AGENTS.md / CLAUDE.md → SKILL.md、SOUL.md
② 上下文与记忆 每一步能看到什么、跨步骤记住什么 RAG、向量库 → 长上下文 → 上下文压缩 → 文件系统当记忆 → MEMORY.md、自动沉淀的技能
③ 工具与行动 能调用什么去改变外部世界 插件 → function calling → MCP → computer use → 内置浏览器与连接器
④ 循环与编排 谁驱动下一步、多个 Agent 怎么分工 人手工复制粘贴 → 开环 AutoGPT → ReAct 闭环 → 工作流与多智能体 → heartbeat 定时自唤醒
⑤ 反馈与验证 怎么判断做对了、错了怎么退 把报错喂回去 → 测试与评测 → 自检、检查点、回退 → 该停下来问人的判断
⑥ 运行环境与权限 跑在哪台电脑、能动哪些东西 云端沙箱 → 本地终端与代码库 → 云端虚拟机 → 平台托管的专属云电脑与凭证
⑦ 交付界面 人怎么看、怎么验收 聊天框 → Artifacts / IDE / 终端 → 多任务管理窗口 → 模型自己生成的界面

图 1：七个部件围绕同一个决策核心。历史就是这七个位置不断被填满、被搬家。

六代划分（注意时间有重叠，不是接力赛，更像层层叠加）：

代 时间 新增的关键部件 一句话结局
第 0 代 2022.11–2023.03 ① 指令（提示词） 人就是 harness
第 1 代 2023.03–2023 底 ③ 工具（插件、function calling）、② RAG 工具调用成为标准，插件商店死了
第 2 代 2023 底–2024 ④ 循环与编排（工作流、多智能体） 用结构换确定性，框架多数被淘汰
第 3 代 2024 Q4–2025 ③ MCP、⑤ 验证、⑥ 沙箱 标准与推理到位，Agent 元年
第 4 代 2025.10–2026.04 ① 技能、⑥ 常驻本地 需求被证明，运维被用户劝退
第 5 代 2026.01–2026.09 ⑦ 界面、⑥ 本地执行 从写代码扩到各类知识工作
第 6 代 2026.05– ⑥ 平台托管、⑦ 生成式界面 电脑搬上云，凭证交给平台

图 2：每一级台阶，都是把上一代最不可靠的那个部件外包出去。

前史：零件早就齐了，只差「自己决定下一步」

  • 语音助手（Siri 2011、Alexa 2014、Google Assistant 2016）：意图、步骤、奖励都得人预先切分。
  • RPA（UiPath 一类）：录制固定流程，界面一变就废。
  • 游戏 AI（AlphaGo 2016、OpenAI Five 2019）：有明确胜负，能自己和自己下几百万盘。

三者卡在同一个地方：世界需要人来切分。而零件在 2022 年 11 月之前已经备齐：Transformer（2017）、GPT-3（2020）、Codex 与 Copilot（2021–2022.06）、WebGPT（2021.12）、思维链（2022.01）、SayCan（2022.04）、Adept ACT-1（2022.09）、ReAct（2022.10）、LangChain（2022.10）、LlamaIndex（2022.11）。

复习要点：缺的从来不是能力，而是把这些能力串成一个循环的那层壳。

第 0 代（2022.11–2023.03）：人就是 harness

一句话：ChatGPT 把模型交给了所有人，但那时整个 harness 长在人身上。

时间 事件 为什么记住它
2022-11-30 ChatGPT 上线 5 天 100 万用户、2 个月月活 1 亿，历史上最快的消费级产品扩散
2023-02 微软投资、Bing Chat 4K 上下文 + 联网；「Sydney」人格失控成了最早的 Agent 事故样本
2023-02 Bard 演示出错 Alphabet 单日蒸发约 1000 亿美元，演示也要被审查
2023-03-14 GPT-4 多模态、考试分数接近人类前列
2023-03-16 文心一言 国内「百模大战」开始；2023-08-15 起实行生成式 AI 备案
2023-03-23 ChatGPT 插件 让模型第一次能「调外部世界」，也是第 0 代的终点

两个结构性缺陷：知识有截止日期、还会编；不能行动，上下文只有 4K。所有需求都被挤到同一个出口——把话说得更清楚。

于是有了「提示词工程师」这个岗位：无需编程、年薪报到 33.5 万美元，PromptBase 上卖提示词成了生意。到 2023 年底，这个岗位基本消失。

教训：把「会说话」当成「会做事」，是这一代所有泡沫的共同来源。

第 1 代（2023.03–2023 年底）：工具调用觉醒

一句话：模型第一次「动手」，但只会动别人替它装好的那几只手。

时间 事件 留下什么
2023-03 ChatGPT 插件商店 一次对话最多挂 3 个插件，2024.04 下线，几乎没留下东西
2023-06-13 function calling JSON Schema 描述工具、模型输出调用参数——唯一活到今天的遗产
2023-07 Code Interpreter 云端沙箱里写代码跑代码，第一个「自己验证自己」的雏形
2023 上 RAG 与向量库热 Pinecone 1 亿美元 B 轮、估值 7.5 亿；Weaviate、Chroma、Qdrant、Zilliz 跟进
2023-07-20 Custom Instructions 人设从一次性提示词变成常驻配置
2023-11-06 DevDay GPT-4 Turbo 128K、GPTs、Assistants API；2024-01 的 GPT Store 号称 300 万个 GPT
2023-03-30 AutoGPT 10 万 star；开环循环，单步 95% 正确，20 步后 95%^20 ≈ 36%
2023.04–05 Generative Agents、Voyager 25 个角色的小镇、会攒技能库的 Minecraft 智能体——后来的多智能体与技能系统的原型

AutoGPT 的爆红和熄火是同一件事：它证明了「让模型自己循环」的想象空间，也证明了错误会累积。

泡沫：GPT Store 迅速沉寂；向量库公司集体降温；「和 PDF 聊天」这类应用被模型自带的文件能力直接吞掉。

教训：外挂越像商店，越容易被平台收走；只有长进模型里的能力留得下来。

第 2 代（2023 底–2024）：用确定的结构换可预期的结果

一句话：既然模型不可靠，就用工作流把它框住。

主题 关键事实
基本循环 ReAct 成为默认：想一步 → 做一步 → 看结果 → 再想
工作流 vs 智能体 Anthropic《构建有效的智能体》（2024.12）：路径写死的是工作流，模型自己定路径的才是智能体。先用工作流，跑通了再放开
四模式 吴恩达（2024.03）：反思、工具使用、规划、多智能体。同一个模型，套上工作流后编程正确率 48% → 67% → 95.1%
长上下文 Claude 2.1 20 万（2023.11）、Gemini 1.5 Pro 100 万→200 万（2024）→「RAG 已死」；但「中间迷失」说明塞得多不等于用得上 → 上下文工程（2025.06 定名）
低代码平台 Dify、Flowise、Langflow、n8n（估值 25 亿）、扣子（2023.12 / 2024.02）、文心智能体、元器、百炼
框架 LangGraph（2024.01）、Swarm（2024.10）→ Agents SDK（2025.03）
多智能体 ChatDev（2023.07）、MetaGPT（2023.08）、AutoGen、CrewAI；反方 Cognition《不要构建多智能体》（2025.06）：Anthropic 的多智能体研究吃掉了 15 倍 token
评测 SWE-bench Verified（2024.08，500 题）；Devin（2024-03-12，13.86%，月费 500 美元）；SWE-agent（2024.04，ACI：不改模型，只按模型习惯重做工具接口）
交互 Claude 3.5 Sonnet + Artifacts（2024-06-20）、Cursor 的 Composer / Agent 模式（2024.11）

泡沫：LangChain「封装之争」；低代码百团大战与「No Code Is Dead」；Rabbit R1（199 美元）与 Humane AI Pin（699 美元 + 24 美元/月，2025-02 被惠普以 1.16 亿美元收购）；Klarna 宣布 AI 顶替 700 人后又回头招人；Salesforce Agentforce 带火「agent washing」（只包装不改造）。

教训：工作流的上限是设计者的想象力；模型一升级，昨天的高级结构就成了今天的累赘。

第 3 代（2024 Q4–2025）：标准、推理、操作电脑

一句话：三块基础设施同时到位，Agent 从「能跑」变成「能信」。

基础设施 起点与关键日期 意义
推理模型 o1-preview（2024-09-12）、o3（2025.04）、DeepSeek-R1（2025-01-20） 思维链被练进模型；R1 让英伟达一周跌 17%、市值蒸发近 6000 亿美元。本质：有可自动判分的任务，就能用 RL 练长链推理
MCP 2024-11-25 发布 把 M×N 个集成压成 M+N。工具 / 资源 / 提示模板三件套。OpenAI（2025.03）、Google（4 月）、微软（5 月 Build）陆续支持；A2A（2025-04-09）6 月捐给 Linux 基金会；ACP / AP2（2025.09）
Computer Use 2024-10-22 发布 OSWorld 15% vs 人类 72%；Operator（2025-01-23）→ ChatGPT agent（2025-07-17）；Comet（2025.07）、Atlas（2025-10-21）
Deep Research Gemini（2024.12）、OpenAI（2025-02-02） 把「查资料」做成 5–30 分钟的报告，第一次卖「过程」而不是「回答」

MCP 的代价同步出现：工具投毒（2025.04 Invariant Labs）、GitHub issue 里藏指令、Simon Willison 的「致命三要素」（2025.06）。

两条轨道：

  • 轨道 A 通用 Agent：Manus（2025-03-06）爆红，邀请码炒到上万；5-13 开放注册（19 / 39 / 199 美元）；8 月 ARR 9000 万，12 月破 1 亿。国内跟出 AutoGLM 沉思、扣子空间、Genspark、Flowith。
  • 轨道 B 编程 Agent：为什么编程先跑通？代码自带验证器——编译、测试、报错都是现成的反馈。Claude Code（2025-02-24 预览 + CLAUDE.md，5-22 正式，9 月 Agent SDK，年底 ARR 10 亿）、Codex CLI（2025-04-16）、Gemini CLI（2025-06-25）、Cursor（ARR 1 亿→10 亿，估值 293 亿，2.0 自研 Composer）、Windsurf 三方交易、Kiro 规格驱动（2025.07）。国内 Kimi K2、Qwen3-Coder、GLM-4.5、DeepSeek V3.1、MiniMax M2 集体跟进开源。

Vibe coding（2025-02-02 提出，柯林斯年度词汇）：Lovable 用 8 个月做到 1 亿美元 ARR；YC 冬季批次里 1/4 的项目有 95% 的代码由 AI 写。

CLI 与 GUI 的分歧在这一代埋下：终端省 token、可组合、模型也熟；但到 2026 年几乎所有厂商又都回头做图形界面（见第 5 代）。

标准之战的阶段性结束：AGENTS.md（2025-08，数万项目采用）与 AAIF（2025-12-09，MCP / goose / AGENTS.md 交给 Linux 基金会）。

代价清单（这一代最该记住的部分）：METR（2025-07-10，16 名开发者 246 个任务，实际慢了 19%，但受试者自认快了 20%）、Replit 删库、Veracode 称 45% 的生成代码有安全缺陷、MIT NANDA 报告称 95% 的企业试点没有可衡量回报、Kiro 事故造成 AWS 中断 13 小时（2025-12）。

教训：模型越能干，你能承受的错就越少；验证能力决定了 Agent 的可用半径。

第 4 代（2025.10–2026.04）：技能封装与常驻

一句话：Agent 从「你叫它才动」变成「一直在线，自己找活干」。

事件 要点
Agent Skills（2025-10） 一个文件夹 = SKILL.md + 脚本 + 模板，先只读 100 token 的描述、需要时才加载正文。把行业经验变成了可移植的文件
OpenClaw 从 Clawdbot 改名而来：跑在自己的 Mac mini 上，SOUL.md 定人格、MEMORY.md 存记忆、skills + MCP 干活、heartbeat 定时醒来。4 个月 25 万 star
Moltbook 只允许 Agent 发帖的社交网络：1.7 万个主人、人均 88 个 Agent
中国「养龙虾」 QClaw 等一键云端部署，把常驻代理变成消费级产品
Hermes Agent 把「学习循环」写进循环：做完任务自动总结成新技能文件（「养马」）
事故 ClawHavoc 恶意技能窃取本地密钥 → 技能来源审核、权限隔离成了必答题

教训：记忆和技能可以外挂，信任不能。

第 4 代的退潮（2026.03–09）

一句话：证明了需求成立，没证明人人愿意自己运维一台机器。

退潮原因：普通用户不想维护一台全天开机的电脑；安全事件接连出现；模型公司把「常驻」直接做进了自己的产品。

具体表现：腾讯 QClaw 宣布 12 月停运；「一人公司」（OPC）热在地方补贴推动下升温，秋天暴露出社区空心化和低存活率；「养马」热度相对平稳，Hermes 保持稳定迭代。

但设计没死：常驻运行、主动执行、文件式记忆，几乎原样出现在第 6 代的托管代理里。

教训：退潮淘汰的是产品，不是设计。

第 5 代（2026.01–2026.09）：Work 化

一句话：Agent 从写代码扩展到成块的知识工作，界面之争重新开打。

时间 事件 为什么是转折
2026-01-12 Claude Cowork 研究预览 读写你授权的文件夹、自己定计划、多步执行、随时叫停；1-30 出 11 个岗位插件
2026-01-12 → 02-23 软件股累计跌约 25% Jefferies 称之为「SaaSpocalypse」（SaaS 末日）。逻辑：按席位收费的软件被 Agent 绕过了界面
2026-03-09 微软 Copilot Cowork 底层是 Anthropic 的 Cowork——入口方把办公 Agent 交给模型方
2026-02 → 07 OpenAI 的合并路线 Codex app（2-02 macOS / 3-04 Windows）→ Frontier 企业平台 → GPT-5.4（3-05，首个原生能操作电脑的通用模型，100 万 token）→ ChatGPT Work（7-09，与 Codex 合并）→ 7-22 周活合计 1000 万
2026-04-02 Cursor 3 新界面「Agents Window」，本地 / 独立工作区 / 云端 / SSH 并行；5 月 ARR 约 40 亿美元（16 个月前只有 1 亿）
2026 上半年 国内「百Work大战」 腾讯 WorkBuddy（3-09，2097 万次/月）、阿里悟空（3-17）→ 千问办公（8-03 三合一）、字节 TRAE Work（6-09）、Kimi Code Desktop（9-17）、DeepSeek Harness（7-31 随 V4 发布）

规模：2026 年 6 月，17 款国内桌面端办公智能体合计访问量超 6000 万次；WorkBuddy 2097 万居首，TRAE IDE 1279 万、QoderWork 788 万；按集团算腾讯系 3262 万、字节系 1441 万、阿里系 919 万、百度 72 万。

这一轮竞争的三个结构性特点：

  1. 参赛者都是分发入口的主人——微信、钉钉、飞书与豆包、Office、ChatGPT。留给独立创业公司的位置很少。
  2. 办公 Agent 是模型公司卖 token 的出口——大厂可以在这条产品线上长期亏损，从模型和云上赚回来；独立公司要向模型公司买 token，每一单都得算得过账。
  3. 订阅价格和执行成本对不上——重度用户跑一晚上的长任务，算力可能是轻度用户的成百上千倍，固定价格的订阅覆盖不了这种波动（Manus 2025 年用积分计价，是最早的补救）。

harness 工程：从提示词、上下文到整套环境

2026 年 2 月，这个词成形。Mitchell Hashimoto 的说法是：「每当 Agent 犯错，就花时间设计一个让它不再犯同样错误的办法。」几天后，OpenAI 发表《Harness 工程：在 Agent 优先的世界里使用 Codex》，把工程师的工作描述成设计 Agent 的代码仓库、文档、约束和反馈回路。

关注点经历过三次扩展：2023 年关心「怎么把请求说清楚」（提示词工程）→ 2025 年关心「窗口里放哪些信息」（上下文工程）→ 2026 年关心「在什么环境和反馈机制下连续工作几小时不跑偏」（harness 工程）。后一段包含前一段，并不取代它。

可以量化的证据：LangChain 只改 harness、不换模型（固定 gpt-5.2-codex），Terminal Bench 2.0 从 52.8 升到 66.5，排名从 30 名开外进前 5；Vercel 反过来做减法，删掉大部分专用工具只留「执行任意命令」，任务成功率从 80% 升到 100%。

「模型是商品，harness 才是护城河」——这句话要打个折扣：能写成博客的部分，行业几周就学走；剩下的是写不进博客的东西——真实任务的轨迹数据，以及据此让模型和产品一起迭代的能力。

终端热与图形界面的回归

推崇终端的理由：模型擅长命令行、文字便于组合与审计、省 token、对开发者友好。2026 年甚至出现了把任意软件转成命令行工具的 CLI-Anything。

但 2026 年的产品走向是反过来的：Codex app、Claude Code 桌面版、Cursor 3、Claude Design、ChatGPT Work、DeepSeek Harness 桌面版、Kimi Code Desktop 全是图形界面。原因：人要同时盯多个 Agent；用户从程序员变成了知识工作者；AI 把做界面的成本打下来了。

拆成两层就清楚了：Agent 调用工具的接口，命令行、API、MCP 确实更有优势；人监督验收的界面，图形界面同样有优势。2026 年的主流形态是「图形界面外壳 + 命令行内核」。

FDE：把 Agent 送进企业的人

瓶颈不在模型，而在把模型接进每家企业各不相同的数据、系统、权限和流程。FDE（前线部署工程师）由 Palantir 开创，2026-05-04 OpenAI 与 Anthropic 在同一天出手：OpenAI 成立 DeployCo（100 亿美元投前估值，融资超 40 亿，TPG 领投，收购英国咨询公司 Tomoro 带来约 150 名 FDE），Anthropic 联合黑石、Hellman & Friedman、高盛成立面向中型企业的 AI 原生服务公司。

两难：派人 → 收入依赖人力，毛利向咨询公司靠拢；不派人 → 把经验沉淀成技能与插件，但每家企业的流程不同，标准化很快碰天花板。一句话概括：进则外包化，退则天花板。

模型、评测与钱

  • 时间跨度：METR 2026 年 2–3 月报告称 Claude Opus 4.6 约 12 小时（置信区间 5–61 小时）；5 月注明「超过 16 小时的测量结果并不可靠」；9-08 起不再积极更新榜单——不是模型停步，是测试题不够用了。
  • OSWorld 2.0（7 月）改用长任务：人类中位 1.6 小时、平均 318 次工具调用（初代只约 30 次）。
  • Anthropic 年化收入：90 亿（2025 底）→ 300 亿（4 月）→ 470 亿（5 月）→ 超 650 亿（7 月底）；2026 Q2 季度收入 115 亿，首次超过 OpenAI 的 67 亿。OpenAI 9 月年化约 500 亿——两家口径不同，别直接比。

专题：Manus 的对错账单

一句话：它证明了「Agent 是一个产品类别」，没来得及证明「Agent 是一家独立公司」。

做对了四件：交付成品而不是回答（还能回放整个过程，回放本身就是传播素材）；押上下文工程、不训练模型（「做上涨潮水上的船，不做钉在海底的柱子」）；第一天就收费（用积分计量，九个月做到 1 亿 ARR）；看准海外付费用户。

猜错了四件：低估模型公司吞掉 Agent 层的速度（「潮水自己开始造船了」）；「通用 Agent」没有成为独立品类，变成了聊天产品里的一个模式、Work 产品的公共底座；云端虚拟机的纯粹性没守住（Browser Operator → Studio）；以为注册地能洗掉研发地。

工程遗产四条（2025 年 7 月公开，后来成了行业公版）：

  1. KV 缓存命中率是第一指标——输入与输出的 token 比约 100:1，只有前缀不变才能复用。
  2. 文件系统当外部记忆——窗口装不下的写进文件，用时再读。
  3. 用 todo.md 反复「背诵」目标——把目标和进度写到上下文末尾，防止长任务跑偏。
  4. 保留错误记录——报错不删，让模型看见自己犯过的错。

按需加载上下文的思路，后来被第 4 代的 Agent Skills 写成了开放格式。

判词：先驱者创造的品类越大，自己的位置可能越小。能留在手里的只有三样——分发渠道、轨迹数据飞轮、能承担风险的主体资格。

第 6 代（2026.05–）：平台托管

一句话：第 4 代的愿景（全天在线的个人代理）由平台实现了，代价是电脑和凭证都搬到了云上。

产品 日期 形态
Google Gemini Spark 5-19 Google Cloud 虚拟机上的「全天候个人代理」，手机关机也继续干；基于 Antigravity，最初由 Gemini 3.5 Flash 驱动
苹果 Siri AI 6-08 WWDC 发布，Siri 15 年来最大改造；基于与 Google 合作定制的 Gemini，跑在设备端 + 私有云计算，9 月上线

继承了什么：全天在线与主动执行（heartbeat）、聊天或短信式界面、长期记忆（SOUL.md / MEMORY.md 的变体）、技能与连接器扩展。

改变了什么：运行位置从用户的电脑搬到平台云端；本地电脑默认隔离；凭证由平台托管；维护与安全归平台；费用从「自己买 API 密钥」变成打包进订阅，Meta 甚至免费。

中国走的是另一条路——超级应用和手机。豆包手机助手（2025-12，与努比亚合作的 M153，3499 元，首批 3 万台售罄）第一次把 GUI Agent 大规模装进量产机，几天后就撞上微信异常、淘宝与银行风控；2026-02 部分 App 与字节「停火」。9-16 第二代 NaviX Ultra（5999 元起）把高风险动作改成逐次确认，并推出 SAEP（屏幕自动化操作声明协议）：开发者可在公示期内声明是否允许，期满未拒绝即默认放行——被称作「AI 时代的 robots 协议」。

留下的问题很清楚：如果超级应用只开放查询、不开放交易，手机 Agent 还能剩下多少空间。

交付界面交给模型：GPT-6 的 Intelligent UI

2026-10-07，GPT-6 向全部用户推出，同时上线 Intelligent UI：回答不再只是文字，可以是可点选的示意图、能拖参数的房贷计算器、表单和小组件。模型自己决定「用什么形式回答」，界面随生成逐步出现。

前史是 2024 年的 Artifacts 和 Canvas——把模型生成的东西放进旁边的面板渲染。区别在于：过去是产品决定在哪里、用什么方式展示，现在是模型自己决定。

局限也很清楚：生成的工具不能保存和分享，换个对话就没;同一问题每次布局可能不同；界面越像成品，越没人去核对背后的公式。

意义：⑦交付界面是七件套里最靠近人的一个，2026 年 10 月开始被训练进模型。这和当年思维链发展成推理模型、操作电脑成为原生能力，是同一种过程。

专题：本地还是云端

一句话：争的不是「算力在哪」，而是「材料、登录态和风控在哪」。

先明确一点：所谓「本地 Agent」，模型大多仍在云端——它在你的电脑上读文件、敲命令，但每一步怎么想还是要发回云端。「本地/云端」只指谁执行动作。

年份 云端做了什么 本地做了什么
2023 Code Interpreter 的云端沙箱（不联网、上传限 100MB、单次 120 秒、关闭即清空） Open Interpreter 把同样的能力搬到本机；AutoGPT 用你自己的 API 密钥跑
2024 Devin 的云端沙箱（命令行 + 编辑器 + 浏览器）；Computer Use 的参考实现是 Docker 容器 Cursor 装在程序员电脑上，代码留本地
2025 Operator 的云端浏览器 → ChatGPT agent 的虚拟电脑；Manus 每个任务一台云端虚拟机；云端 Codex、Jules、Copilot 编程 Agent Claude Code、Codex CLI、Gemini CLI 跑在自己的终端；Comet、Atlas 直接用你自己的浏览器
2025 底 Claude Code 推出网页版，会话跑在 Anthropic 托管的沙箱里 Manus 推出 Browser Operator，进入用户自己的浏览器，带着现成的登录状态和本机 IP
2026 上 云厂商推出 OpenClaw 一键云端部署 OpenClaw 装在自家 Mac mini，「本地数据主权」达到顶点；Cowork 的循环在本地跑，执行放进本机隔离虚拟机；WorkBuddy 操作本地文件
2026 下 Spark、Muse、Dots 全部云端托管 千问办公把桌面端、云端、企业协同塞进同一个产品；Manus 2.0 把本地的 Studio 放在前面

七个拉扯因素：材料与登录态在哪、出错会不会伤到真机、能不能一直在线、算力谁付钱、隐私与合规、谁来维护、能同时跑多少任务。

图 3：真正反复摇摆的是中间那层——动作在哪台电脑上执行；推理几乎一直在云端，凭证要么在用户手里，要么在平台手里。

收敛出的答案：客户的电脑优先，云端的电脑兜底。材料、登录态和用户的注意力都在本地；当任务需要长时间运行、用户离开后继续、大规模并行、或需要与真实系统隔离时，再交给云端。

第 6 代却反着来：云端优先，本地按需接入。因为它要的材料——邮件、价格、机票——本来就在网上，而不在文件夹里。

把三层拆开看更清楚：

层 问题 例子
推理在哪 每一步的「想」由谁算 几乎都在云端（少数端侧模型除外）
执行在哪 命令在哪台机器跑、浏览器开在哪 Claude Code 本地 / Dots 云端 / Cowork 本地再套隔离
数据与凭证在哪 文件、密码、登录态由谁保管 用户自己保管 / 平台托管

更一般的规律：Agent 的电脑要放在任务材料所在的地方，也要放在用户离开之后仍能继续运行的地方。两个条件指向不同位置时，产品就会同时提供两台电脑。

截至 2026 年 10 月仍悬而未决的问题

年初业内押的四个方向，兑现得并不均匀：

  • 闭环：执行闭环基本靠 harness 兑现（测试、规范检查、截图比对）；时间闭环兑现了一部分（能跑数天的异步任务），但测量工具先撑不住了；认知闭环几乎没动——产品里的替代做法是硬规则，比如支付、发布必须逐次确认。
  • 内在记忆：没有主流产品把持久状态做进基座模型；「文件即记忆」这条外挂路线反而成了默认。
  • 世界模型：钱都去了机器人（AMI Labs 约 10 亿美元融资、估值约 45 亿；Genie 3 生成可交互世界）；数字 Agent 这一侧没有落地，预演仍靠沙箱试运行。
  • 具身化：Gemini Robotics 1.5 / 2、1X NEO 开始交付、宇树 8-19 上市首日涨约 629%、9 月腰斩、10-09 市值约 1750 亿——热度与落地时间表背离，王兴兴自己说通用场景落地最快 2–3 年、最慢 5–10 年。

六个还没有答案的问题：

  1. 独立的 Agent 公司能不能存在。Cursor 在垂直领域的高速增长说明还有机会，但还没有哪家独立通用 Agent 公司证明自己能长期存活。
  2. Agent 的电脑放在哪。Work 类产品收敛到「本地优先、云端兜底」，第 6 代又选了云端优先。
  3. 代理的身份与访问权。亚马逊 2025-11 起诉 Perplexity，2026-03 一审禁令要求暂停用 Comet 下单，2026-08-04 第九巡回上诉法院认为「访问的是用户本人，Agent 只是工具」，9 月 Perplexity 据此请求驳回——但一个多月后，亚马逊照样在 9-20 屏蔽了 Meta 的 Muse。Cloudflare 2025-05 提出 Web Bot Auth，2026-08 干脆给 Agent 发身份和钱包。中国这边，是豆包手机与微信、淘宝的摩擦，以及 SAEP 协议。
  4. 收入与估值的口径。两家计算方式不同，投资者难以比较；如果 Anthropic 年内上市，审计过的数字会成为检验。
  5. SaaS 会不会被掏空。抛售反映的是担心，但到 10 月还没有系统性数据；同时微软也在把 Agent 装进自己的产品。
  6. 界面会不会被生成取代。一次性 UI 解决了「软件适应人」，还没解决保存、共享和核查。

终论：十条规律

# 规律 一句话证据
1 基座模型能力决定 Agent 形态 上下文变长才有工作流，推理变强才有长任务，视觉成熟才有操作电脑
2 Harness 持续扩张：新部件先外挂，成熟后标准化或练进模型 function calling → MCP；提示技巧 → 思维链 → 电脑操作 → 2026 的界面生成
3 开放协议降低接入成本，价值却向少数公司集中 MCP / Skills 人人可用，但前沿模型仍受限开放，收入向模型公司集中
4 Harness 的边界不断外移，每次外移都伴随事故与修补 Replit 删库、Kiro 事故之后，最小权限与人工确认成了共识
5 事故与商业协商共同塑造标准 安全事件倒逼规则；SAEP、Agent 身份方案则是企业协商出来的
6 炒作的「爆发—灭绝」循环仍在重复 插件、AutoGPT、低代码、OpenClaw、百Work大战，六个月内见分晓
7 能被描述的东西都会公有化 Manus 的上下文工程成了公版，技能文件既好携带也好复制
8 主权风险成为必须定价的变量 「技术源于中国」四个字叫停了一笔 20 亿美元的收购
9 分发入口决定普及速度 Muse 靠 Meta 的用户量登上榜首，WorkBuddy 靠微信与企微居首
10 落地的瓶颈从技术转向组织 FDE 走红，OpenAI 与 Anthropic 同一天成立部署公司

从 2022 到 2026，Agent 从「被动对话」走到了「自主数字劳动力」，Harness 也从一句提示词长成了一整套运行系统。接下来的问题几乎全部落在 Harness 的最外层：它以谁的身份行事、能进哪些门、跑在谁的电脑上、交付的成果由谁来核查。
