为什么关注这套工具

Python 项目从创建到持续维护，通常要处理解释器版本、虚拟环境、依赖安装与锁定、代码格式、静态检查和类型检查。uv、Ruff、ty 分别覆盖其中不同环节，可以组合成一条简洁的日常开发流程。

工具 主要用途
uv Python 版本、虚拟环境、依赖与项目命令管理
Ruff 代码检查与格式化
ty 静态类型检查

它们不会替代测试。测试负责验证程序运行时行为，静态检查则能在运行程序前发现一部分问题。

记忆要点

  • 用 uv add 管理项目依赖，用锁文件保持环境可复现。
  • 用 Ruff 同时处理 lint 和格式，团队共享一份规则配置。
  • 用 ty 找出类型使用上的不一致，再通过类型标注表达代码意图。
  • 静态检查和自动修复之后仍需运行测试。
